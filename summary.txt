# SYSTME-APPs Project Summary

This document provides a comprehensive overview of the SYSTME-APPs project architecture, which consists of three main components: Frontend, Backend, and an AI Model.

## 1. Frontend Architecture
The frontend is a modern Single Page Application (SPA) built with React and Vite. 

**Key Technologies:**
- **Framework:** React 19
- **Build Tool:** Vite (for fast development and optimized production builds)
- **Routing:** React Router v7 (`react-router-dom`)
- **HTTP Client:** Axios (for communicating with the backend and AI model APIs)
- **Internationalization:** i18next & react-i18next (with browser language detection)
- **Styling/Icons:** RemixIcon and FontAwesome 
- **Utilities:** jsPDF (likely for generating invoices or reports as PDFs) and React Joyride (for interactive user onboarding/tours)

**Purpose:**
It serves as the user-facing interface, likely for an auto repair shop management system or customer portal, where users can book appointments, view estimates, and interact with the AI for repair diagnostics.

## 2. Backend Architecture
The backend is a robust RESTful API built with the Laravel PHP framework.

**Key Technologies:**
- **Framework:** Laravel 12 (PHP 8.2+)
- **Authentication:** Laravel Sanctum (for secure, token-based API authentication for SPAs)
- **Database:** Uses Laravel's Eloquent ORM with migrations and seeders (likely SQLite/MySQL based on project config)
- **Testing:** PHPUnit and Mockery (extensive test scripts exist in the root like `test_api.php`, `test_appointments.php`)
- **Development Tools:** Laravel Telescope (for debugging) and Tinker

**Purpose:**
The backend acts as the core system of record. It handles business logic, user authentication, data persistence (such as saving appointments, user profiles, and repair history), and acts as an intermediary for secure operations.

## 3. AI Model Architecture
The AI Model is a standalone Python web service that provides predictive diagnostics for vehicles.

**Key Technologies:**
- **Framework:** Flask (with Waitress for production serving)
- **Machine Learning:** Scikit-learn and XGBoost
- **Data Processing:** Pandas and NumPy
- **Model Storage:** Joblib (loading pre-trained `.pkl` models)
- **API:** RESTful endpoints with CORS enabled

**How it Works:**
The service exposes a `/predict` endpoint that accepts POST requests containing vehicle details (make, model, year, mileage, symptoms, etc.). 
It runs these inputs against three loaded models:
1. `repair_model.pkl`: A classification model that predicts the top 3 most likely repairs needed along with confidence percentages.
2. `cost_min_model.pkl`: A regression model that predicts the minimum estimated cost (in MAD - Moroccan Dirham).
3. `cost_max_model.pkl`: A regression model that predicts the maximum estimated cost.

**Purpose:**
It provides an intelligent "Auto Repair AI" feature for the application. When a user inputs their vehicle's symptoms, the AI estimates what's wrong and how much it will cost to fix, enhancing the booking or estimation process.

## Summary of Data Flow
1. The **Frontend (React)** provides the UI for the user to input vehicle symptoms or book an appointment.
2. For intelligent estimates, the Frontend calls the **AI Model (Flask)** API to get repair predictions and cost estimates.
3. For saving data (like booking an appointment based on the estimate) or fetching user history, the Frontend communicates with the **Backend (Laravel)** API securely using Sanctum tokens.
